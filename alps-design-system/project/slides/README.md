# ALPS Slide Templates

Boardroom‑style slides for ALPS engagements. All slides are 1920×1080, designed to look at home in a Big 4 deliverable.

## Slide types

- `01-title.html` — title slide with the wordmark, engagement title, and dateline.
- `02-section.html` — full‑bleed navy section divider with eyebrow + heading.
- `03-comparison.html` — two‑column compare/contrast.
- `04-big-quote.html` — pull quote with attribution.
- `05-data.html` — three editorial stat callouts.
- `06-closing.html` — closing slide ("Begin a conversation").

Open `index.html` for a navigable deck combining all six.

All slides use `../colors_and_type.css` and the brand assets in `../assets/`.
